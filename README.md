# СловоИгра (word-play)

PWA-тренажёр речи и игры в слова для детей с задержкой развития и РАС.

## Стек

- Angular 22 (standalone components)
- Angular Material
- PWA (`@angular/pwa`)

## Запуск

```bash
npm install
npm start
```

Приложение откроется на `http://localhost:4200`.

## Сборка

```bash
npm run build
```

## Структура

```
src/app/
├── core/
│   ├── data/categories.ts   # глобальные категории (эмоции, цифры, море)
│   ├── models/
│   ├── services/
│   └── utils/
├── features/
│   ├── welcome/
│   ├── games/
│   ├── build-word/          # игра «Собери слово»
│   └── parent/
└── shared/ui/         # переиспользуемые UI-компоненты
```

## Экраны

1. **Приветствие** — выбор роли (ребёнок / родитель)
2. **Игры** — карточки с типами игр (пока без самих игр)
3. **Настройки родителя** — сложность, ограничения, включение игр
4. **Собери слово** — выбор категории → сбор букв в слова (drag-and-drop и клик)

Настройки сохраняются в `localStorage`.
