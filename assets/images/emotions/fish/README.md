# Рыбки-эмоции

Положите сюда картинки для категории «Эмоции» в режиме «Рыбки».

## Имена файлов

Формат: `f_<id>.jpg` (также поддерживается `.png`)

| Файл | Эмоция |
|------|--------|
| `f_happy.jpg` | я радуюсь |
| `f_sad.jpg` | мне грустно |
| `f_afraid.jpg` | я боюсь |
| `f_angry.jpg` | я злюсь |
| `f_surprised.jpg` | я удивлён |
| `f_ashamed.jpg` | мне стыдно |
| `f_thinking.jpg` | я думаю |
| `f_proud.jpg` | я горжусь |
| `f_bored.jpg` | мне скучно |
| `f_delighted.jpg` | я в восторге |

Рекомендуемый формат: JPG или PNG, квадратное изображение.

Если файл не найден, игра покажет эмодзи.
